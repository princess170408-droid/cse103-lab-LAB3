## Overview

This repository contains practical lab work for LAB 3 of the Computer Fundamentals & Career Pathways (CSE103) course at K.R. Mangalam University, Gurugram.

The project demonstrates GitHub collaboration, version control, Markdown documentation, and API interaction.


```bash

```

